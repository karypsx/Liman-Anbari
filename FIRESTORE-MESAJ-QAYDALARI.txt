MESAJLAŞMA, FAYL VƏ BİLDİRİŞ QURASDIRMASI

1. Firebase Console → Firestore Database → Rules bölməsində bu qovluqdakı firestore.rules faylının tam mətnini yayımlayın.

2. Fayl yaddaşı üçün bu qovluqdakı SUPABASE-QURASDIRMA.txt təlimatını izləyin. Fayl yükləmək üçün Firebase Storage Rules lazım deyil.

3. Mesaj push bildirişi istəyəndə Firebase CLI ilə aşağıdakı qaydaları və funksiyanı yayımlayın:

    firebase deploy --only firestore:rules,functions:sendChatMessageNotification

Cloud Function yayımlamaq Firebase Blaze planı/billing hesabı tələb edə bilər. Bu, Supabase fayl yaddaşından ayrıdır. Funksiya yayımlanmayıbsa, söhbət və oxunmamış sayğaclar işləyir, amma tətbiq bağlı olanda push bildirişi göndərilmir.

Mesaj panelinin nişanı bütün söhbətlər üzrə oxunmamışların cəmini, istifadəçi siyahısındakı qırmızı dairə isə həmin şəxsdən gələn oxunmamışların sayını göstərir. Söhbəti oxuyanda həmin şəxsin sayğacı sıfırlanır.
