MESAJLAŞMA VƏ PUSH BİLDİRİŞ QURAŞDIRMASI

1. Firebase Console → Firestore Database → Rules bölməsində firestore.rules faylının tam mətnini yayımlayın.

2. Faylların Supabase-ə yüklənməsi üçün SUPABASE-QURASDIRMA.txt faylındakı addımları tamamlayın. Firebase Storage Rules lazım deyil.

3. Push bildirişi üçün layihənin əsas qovluğunda terminal açıb işlədin:

    firebase deploy --only firestore:rules,functions:sendChatMessageNotification

Firebase CLI hesabında limananbari layihəsinin seçildiyini yoxlayın. Cloud Function yayımlamaq Firebase Blaze planı/billing hesabı tələb edə bilər. Supabase fayl yaddaşı bundan ayrıdır.

4. Hər cihazda mesaj panelinin başlığındakı zəng düyməsinə basıb bildiriş icazəsini aktiv edin. İcazə verilməsə mesaj yenə söhbətdə görünür və qırmızı oxunmamış sayğac artır, amma push gəlmir.

İstifadəçi siyahısındakı qırmızı nişan həmin şəxsdən gələn oxunmamış mesajların sayını göstərir. Push bildirişinə basanda göndərənlə söhbət açılır.
